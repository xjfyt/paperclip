# 反馈 → 固定回归集来源链

## 已实现范围

- 复用既有 `mimouse_evaluation_datasets.cases` JSONB、固定集哈希和历史测试比对；不新增表/迁移，不修改已有数据集，不重新计算旧哈希。
- “技能回归评估”页面提供可选反馈来源入口：填写已有 skill test input ID、反馈 ID、精确预期输出 → 预览 → 人审声明 → 加入 JSON 草稿 → 明确冻结。
- 预览仅供真实登录、当前 active 公司 owner/admin；写入再次在事务中检查同一公司的当前成员身份。旧无反馈数据集保留原本 local board 行为。
- 来源持久化公司、反馈 ID、来源实例/事件、软件版本、commit/trace 引用、导入内容摘要、当前脱敏记录摘要、脱敏协议版本、人审者与确认摘要；未知 commit 保留 `null`。
- 确认摘要绑定公司、操作者、skill/input ID、输入原始空白与实际 trim 后输入、精确 expected、来源元数据及脱敏记录摘要。事务读取加 SHARE 锁，数据变化返回 409，必须重新预览。反馈/输入不存在、跨公司或输入已删除均拒绝。
- 数据集不复制反馈正文、标题、来源 URL 或私有任务内容。来源仍明确 `quarantined` / `not_reproduced`；`redacted=false` 仅说明脱敏器没有替换字符，不能据此误判为未走脱敏流程。

## 安全与证据边界

“已审核/脱敏”仅记录人的申报，不是自动安全证明；不会解除反馈隔离、赋予执行权限或证明问题已复现。反馈摘要不能替代人工检查源记录。当前不提供反馈复现回执、修复完成回执或自动生成测试。

执行内容仍是既有人工维护的 skill test input。本入口不复制反馈到输入、不调用模型、不启动测试、不向 Langfuse/企微/其他服务发送内容。现有比较器只读取已记录的 skill test runs；无运行记录时仍显示 blocked，而非人审即通过。

旧数据集既不自动回填来源，也不被标成已经确认；含来源的新数据集哈希包含该来源快照。历史数据仍按既有算法比对。输入后续编辑不会改写冻结数据集，旧运行只有与冻结输入一致才可比对。

## API

1. `POST /api/companies/:companyId/skill-evaluations/datasets/feedback-preview`
   请求 `{skillId,inputId,expected,feedbackId}`；返回精确输入、expected、最小来源引用和 `previewDigest`，不写数据。
2. 既有 `POST .../datasets` 的某个 case 可增加
   `feedback: {feedbackId,previewDigest,reviewed:true}`。无此字段时兼容旧请求。
3. 同 requestId、同正文、同人重试返回原数据集；修改正文重用 requestId 冲突。新增来源字段不能由调用方伪造。

## 自动检查与人工验收

已编写并运行 26 条定向服务/权限测试、11 条界面测试（显式解析到独立 worktree 的 shared/db 源码），并通过 token gates 与 git diff --check；类型检查和整库构建由集成阶段统一执行。自动测试覆盖精确摘要、数据变化拒绝、当前成员检查、正文不复制、旧哈希兼容、缺少运行时不通过、四语边界提示、编辑清空确认、切换上下文清空预览、晚返回不恢复旧证据与失败提示。测试中使用隔离的模拟事务；真实 PostgreSQL 竞争、实际浏览器和部署会话仍需下述验收，不能把单元测试当作这些环境已通过。

人工验收（使用虚构且已检查脱敏的数据）：

- [ ] 合成四语贡献后，在英文、中文、西语、日语确认入口及边界文案正确；旧数据集仍可正常显示与比较。
- [ ] 使用真实 active owner/admin 登录，准备同公司人工输入和反馈；预览展示准确输入/expected/来源 ID，不含反馈正文、标题、URL。未勾声明不能加入草稿，加入草稿不应创建数据集或启动执行。
- [ ] 明确冻结后检查返回数据集和数据库 JSON：来源、人、摘要与哈希完整，未知 commit 为 null，来源仍 quarantined/not_reproduced，审计仅记录 digest。
- [ ] 在预览后编辑输入/变更反馈（测试环境）再冻结应 409；撤销成员身份/停用公司应拒绝。换操作者不得重用旧确认摘要。
- [ ] 跨公司反馈/输入 ID、已软删输入、无真人 local board、agent、普通成员、暂停成员必须拒绝新关联；旧 local board 无来源创建仍可用。
- [ ] 连点/网络超时重试只形成一个数据集；修改草稿后新 requestId，原 requestId 不可改变内容。
- [ ] 切公司、换账号、换 skill、编辑 expected 时旧预览与勾选不得带入；请求中的字段禁用，晚返回不得恢复旧页面内容。
- [ ] 为固定集提供真实历史运行前结果必须 blocked；确认新增来源没有被拼入任何执行 prompt，没有外部网络发送。

关联保存发生未知网络结果时，当前组件锁定原 payload/requestId，只提供同请求重试；不会编辑后自动换 ID。导航、刷新、换会话或认证重验导致组件重挂时会清除内存草稿，本切片不持久化 prompt/expected，也没有跨刷新未知写入恢复查询端点。组件重挂后应先检查数据集历史（名称、来源摘要等），不能声称 exactly-once。重复数据集不等于重复派工。

本切片不宣称 P3 复现闭环或 P5 全流程已完成；真实复现、真实测试运行及其回执仍是后续验收/实施项。
