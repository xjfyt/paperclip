# 候选版尚未完成的工作

本文件区分实现缺口与外部验收条件，不用缺少账号掩盖尚未实现的代码。以验收 CSV 和测试日志为准，不将 C2 模拟协议写成真实连通。

## 可继续开发的实现缺口

- 国际化：主导航和高频页面主要标签已接入；复杂筛选、对话框、动态错误及部分上游页面仍需抽取。1396 个键不是覆盖率分母，37文件500条待人工审核的直接语法候选另列CSV。所有新增技术状态也需检查是否应翻译显示标签。
- 编码闭环：当前是固定 SHA 的人工同步/审阅/发布候选台账。持久自动 CI 轮询已接入默认关闭的只读 worker，有限修复调度已接入默认关闭 worker，复用例行任务并限制版本、工作区、次数和费用；真实供应商修复闭环尚未验收，派发窗口不等于运行中强制截止。
- 通知：钉钉应用/公众号自动凭据刷新与共享加密 token 缓存已接入并通过C2数据库测试，真实租户仍待验证。配置修订/CAS/只读历史已补齐；人工投递核对证据已接入且不改写传输结果；供应商自动查询及配置验证级别仍需完善。普通个人微信或个人群没有伪成功驱动。
- 能力展示：七项展示面板已实现并区分C2、未实现、未知。真实账号的审计化验证记录尚未接入，不由安装或配置状态推断C3/C4。

## 原v2计划后续阶段的实现范围

这些是当前尚未完成的机制，不把缺少外部账号当作实现完成的理由：

- P1：高频页面剩余文案、验证等级的可审计证据、通知合并窗口与告警策略、生产升级/恢复演练继续推进。已补齐本地身份邀请、绑定、注销、成员暂停及管理员session/Board key撤销；实际Casdoor停用仍待联调。
- P2：交付记录已逐条保存GitLab项目与SHA，仍需多项目隔离实测/汇总、代码差异审查、六项OS/架构矩阵与Runner证据、上传合同适配。没有机器或上传合同的项必须明确blocked，不能由Linux产物哈希替代。
- P3：尚无公司内的统一反馈入站/日志引用、去重聚类候选及人审转任务闭环。上游feedback服务主要是产品反馈导出，不得直接拿来向外发送客户内容；可以复用纯脱敏函数，不默认开启其外部共享。
- P4：已有routines可作调度底座，但可追踪来源的调研/差距候选、人审转开发和业务数据dry-run/差异/审核/幂等/对账机制尚需实现。不会在没有接口与授权时真实记账或修改外部业务数据。
- P5：已有通用paperclip-eval-kernel，但技能/提示词版本、固定数据集、评分比较、受控提升与回滚的业务台账及成本路由还未形成完整产品闭环。持续迭代不等于一次执行完成所有未来优化。

## 不能由模拟通过替代的验收

- Casdoor：实际 issuer/discovery、已注册应用、两个测试账号、邀请与公司隔离、注销/停用行为。
- Qoder：实际账号、额度、允许工作区与真实任务；官方 CLI 1.1.78 仅验证了版本、帮助及参数检查。
- WorkBuddy：已审核应用和个人 OAuth、实际任务与 ACP/overview 报告、断线恢复、额度。代码回传、强制远端取消不声称支持。
- 通知：明确测试收件人及发送授权、机器人/模板/账号资格、实际送达与供应商限流。
- GitLab：实际测试项目/权限/网络、Runner 和目标版本能力。跨平台构建、签名与上传服务合同另行提供。
- 浏览器：已通过助手云桌面原生终端启动独立实例，由真实 Chrome 验证首次引导、四语任务详情、审批和暂停通知界面。命令会话直接启动 Chromium 的限制仍在；实际中文输入法组合、全部复杂页面和真实供应商登录流程未全量验收，React/jsdom/API 测试不替代这些检查。

## 推进与停止边界

按可审查切片继续完善上述实现缺口，完成类型/构建/本地协议测试后再实连。不得为获得绿色结果跳过安全检查、删除失败测试、默认执行收费探针、向未确认的收件人发通知、自动合并/tag/生产发布。环境状态与具体检查结果应写入最新验证报告，不在本文件固化为永久不可解决。
