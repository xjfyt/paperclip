环境：助手自己的云 Linux 桌面 Chrome；不是用户电脑。命令执行会话与桌面网络隔离，因此在云桌面原生终端启动另一个专用 local_trusted 实例与 embedded PostgreSQL，使用相同已构建 UI。未关闭 socket 安全限制，未创建独立 Codex/工作模式任务。

测试组织只包含测试数据；过程使用 process 适配器 `/usr/bin/true`，不调用付费模型。通知 worker、GitLab 推送/轮询和修复派发关闭。以下只描述实际操作，不用单元测试替代浏览器检查。

## 已实际观察

- 首次组织命名页面四语切换，西语刷新保持；修复语言选择入口缺失及日语标题断行。
- 通过 UI 创建中文组织，继续到 Agent 名称和模型来源步骤；未选择或授权实际供应商。
- 发现进入模型步骤即初始化本地登录的缺陷：增加 sourcePicked 条件，取消此前测试登录尝试；无完成授权、无模型调用。121 项相关 React 回归另行通过。
- 通过 UI 创建中文任务 MIM-1，打开详情；中文标题和正文持久保存。
- 816 键 UI 快照实际切换中文、英文、西班牙语、日语任务详情。状态、任务属性、导航、日期与相对时间显示切换；中文用户内容不变，日语刷新保持。
- 中文概览展示 Agent/任务数量、预算、审批数量和图表标签。
- 打开预置的“浏览器审批验收（无外部操作）”，展开完整请求确认仅本地测试，点击批准，状态变为已批准且收件箱待办数消失。

- 打开本地进程 Agent、最近运行、任务链接和运行事件。run succeeded 表示 true 进程退出成功，不代表任务完成；任务仍进行中，页面没有将两者混为一谈。
