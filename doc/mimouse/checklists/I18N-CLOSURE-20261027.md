## 4. 用户手测步骤（默认未执行）

先记录实际拉取的完整SHA、浏览器/系统、缩放与窗口大小；用可丢弃合成公司及非敏感假数据，不使用真实公司做删除试验。依次切换四语，每项分别填写结果，不因一种语言通过而勾选四种。

3. **导航与连接**：分别验证streamlined/production壳，设置栏目、账号菜单、项目展开/收起/排序与选中状态。四语长文本在窄栏和高缩放下可读，键盘焦点/aria标签清楚；名称/SHA和链接保持原样。断网后恢复，横幅状态和真实连接一致，不凭提示认定重连成功。
4. **费用/额度**：分别准备正常账号额度、有账号但无额度、加载/失败，以及Claude/Codex旧订阅回退的受控响应。检查重置、已用比例与无额度说明；未知费用/额度不显示为0或可用。供应商实际额度与付费行为须另获授权实测。
