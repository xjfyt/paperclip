## CHAT-MODEL：模型设置与组合输入

1. 在中文、英文、西班牙语、日语分别检查桌面弹层与窄屏对话框：设置标题、模型/effort、默认值、返回/关闭、重置、说明、加载/空目录/失败重试与ARIA标签一致。
2. 保留已有任务草稿，搜索Agent及手工模型ID。使用真实中文/日文输入法：组合态Enter只能确认输入法候选，不能选择负责人/模型或发送任务；组合结束后的普通Enter仍只执行既有选择动作。
3. 切换语言并返回弹层，检查草稿、选中模型/effort的原始值和技术标识未被翻译或重置。关闭、Escape、返回、重新打开也应可继续正常输入，不遗留“正在组合输入”状态。
4. 在专用mock或故障环境检查目录加载失败与明确重试；语言切换不应自动反复请求目录，更不能调用模型。不要通过实际收费任务验证翻译。

## RUN-TEXT：运行记录标签与原文边界

1. 使用已有脱敏记录检查User、Decision、审批/拒绝/超时、工具分组、系统生成空态及实际AgentDetail加载/空态四语。
2. 展开记录后切换语言，确认展开状态与流式节点未重建；原日志、代码、工具结果、模型ID、用户名称及未知供应商消息保持原样。
3. 单独检查成功/失败但内容为空的工具结果；未知状态不能被翻译成成功。调用方自定义的 `emptyMessage` 原文应保留。
4. 当前实际工具主要由分组路径渲染；未消费分支有译文不等于对应交互已实测。窄屏换行、长日志滚动和真实流式更新需记录浏览器及OS版本。

## COMMENT-UNKNOWN：未知结果不重放

1. 在未指派的测试任务模拟发送后断网/响应丢失；提示必须明确“可能已保存”，冻结再次提交，并保留原草稿及同一提交身份。
2. 切换四语，不应新增发送请求、清空草稿或绕过未知状态。检查网络面板只用脱敏测试数据，不上传cookie、token或完整本地存储。
3. 回读会话失败时显示本语言错误，仍不能丢弃并开始新稿；成功回读后才显示明确的本地丢弃入口。
4. 点击丢弃前，应能看到“不会删除已保存评论或已上传文件”的说明。丢弃只能清理本地草稿，不得向服务器发送删除或重复评论请求。
5. 本地存储不可用、回读pending、重复点击及切换语言分别复验；真实浏览器断网时序和存储权限行为不能由jsdom测试代替。
