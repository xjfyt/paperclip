# 四语覆盖与剩余项

当前资源为 577 个唯一键，en / zh-CN / es / ja 四语键集合一致。此数字是资源键数量，不是全应用覆盖率。

已接入：无公司入口、登录/单点登录文案、两种 Sidebar 的静态导航与语言选择、组织切换菜单和命令面板、已知状态徽标；新增通知、WorkBuddy、编码交付页的静态系统文案；任务列表/详情/创建、Agent、审批、routines、费用页的一部分高频标签、空状态和按钮。金额、日期、数字与相对时间通过既有入口按语言格式化，不改变业务时区、货币或原始金额。

仍有英文：上述既有页面的部分动态文案和拼接句、复杂筛选/对话框、Runner Inspector 高级调试界面、业务错误、新集成页的原始协议状态与错误码，以及未触及的其他上游页面。因此不宣称四语全覆盖。用户正文、代码、ID、模型输出、自定义状态标签不翻译。

领域源：`ui/src/i18n/contributions/<domain>/<locale>.json`。运行 `node scripts/compose-mimouse-locales.mjs`，使用 `--check` 验证生成物一致、四语键/占位符/URL 一致以及不安全内容。仅注册四语；保留其他上游 locale，不假装已同步。浏览器语言只作为无已保存偏好时的候选，zh-TW/Hant 不冒充已翻译繁体中文。

界面已通过针对性 React 测试和类型/构建检查，上游全 UI 回归分 73 批执行，728 个文件、8187 项测试通过，期间源码摘要保持不变。第二轮577键接线工作树再次跑完整728文件；曾出现一项来源提示空格回归和一个进程被SIGKILL的批次，修复并完整重跑这两批后合计8193项通过。随后西语术语整理另跑33项相关回归。真实浏览器不包含在这些数字中。真实 Chromium 因执行环境权限受限尚未运行成功，不能称视觉或浏览器端到端验收通过。
