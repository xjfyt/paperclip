# 调研候选与人工转开发

本切片是公司私有的人工证据导入与范围确认，不是浏览器搜索引擎、模型调研或定时任务执行器。URL、检索时间和原文摘录来自导入者声明，系统未独立检索或验证来源。任意外部文本均视为不可信证据，不能授权执行。

## 数据与来源

共享researchCandidateSchema要求标题、适用产品、当前能力、目标能力、建议和1–20条来源。每条来源必须有HTTP(S) URL、带时区的ISO检索时间和有限长度证据摘录。已知凭据文本脱敏；URL去除userinfo/query/fragment以减少敏感值持久化。需要依赖query参数才能定位的网页必须另行提供无敏感值的规范引用或在证据中说明定位限制，不能声称截短URL与原页完全等价。任意个人信息不能靠有限规则保证全部发现，导入前需审阅。

0348保存不可变脱敏快照与SHA-256，原始请求只保留摘要用于幂等冲突判断，不存原始敏感文本。公司/requestId唯一；同一actor和完全相同请求可恢复原记录，其他内容或actor不能替换。列表仅返回摘要，详细证据通过公司授权后读取，分页游标不能跨公司。

## 范围确认

只有真实session且当前公司active owner/admin可以确认，不接受Agent、local_implicit、已暂停成员或普通viewer的确认。审核输入必须包含当前evidenceHash、确认的范围、预期收益假设、验收条件和依赖任务UUID。当前owner/admin是产品负责人权限的首期映射，并非另加全局角色。

新任务与确认回执在同一事务创建；请求锁和候选行锁保证并发只生成一项。任务为private/backlog、由确认人负责、无Agent或用户执行分配，并标记low_trust_review/quarantined。证据在动态长度代码围栏中呈现，不执行网页指令。调用原有issueService创建真实blocks依赖边，拒绝跨公司、不可读或不存在的依赖；管理员身份不等于其他人的私有任务访问许可，不隐式启用break-glass。

GET确认状态只向原确认人返回任务回执，其他公司管理员仅知道已确认，避免泄露私有任务地址。重复相同请求恢复原回执，改变范围或新请求重新确认同候选409。撤销成员资格仍阻止再次确认。

## 接口

- POST /api/companies/:companyId/research-candidates：导入或恢复，201/200。
- GET 同路径：limit 1–100与beforeId摘要分页。
- GET /:id：公司管理员详细证据。
- GET /:id/promotion：本人确认回执或已确认标记。
- POST /:id/promote：confirm、expectedEvidenceHash、范围、收益、验收和依赖。

全部接口按敏感集成日志策略处理，不能把请求体/错误上下文的证据直接写入普通HTTP日志。未提供编辑或覆盖已保存证据的接口，新结论应创建新候选。
