# P5 受控提示词应用：界面验收范围

日期：2026-10-26

本记录仅说明开发实现与离线检查；不构成真实模型执行、费用、外发或启用授权。服务端运行时安全及数据库集成由对应实现独立验证。普通应用默认关闭，UI 没有启用开关。

## 已接入的操作

- 历史比较通过后，操作者显式选择“用于应用审核”；比较或打开页面不会自动准备、审批、派发或唤醒。
- 输入单个目标 Agent，读取当前 head/generation，准备绑定固定 revision/report/目标配置/实现摘要的提案。
- 审批前展示原文追加位、本地环境、模型、范围及摘要，并要求四项独立确认：普通日志与工具/产物可见性、bare 比较不证明普通工具质量、新建无项目任务首次 fresh 范围、配置不等于运行授权。
- 审批截止时间只限制待审批提案；配置后的绑定不会在 60 分钟后隐式失效。后续派发仍由服务端重验权限和漂移。
- 当前绑定回退采用 head/generation CAS，仅撤回绑定，不恢复整份 Agent 配置或 secrets，不停止已有运行、不释放其租约、不宣称撤销历史工具影响。公司有权限的管理员可以查看其他管理员的元数据并回退其当前绑定，但不能替其审批。
- 配置、派发准备、实际派发分别显示；prepared但无派发见证仅表示尚无原文交付见证，普通元数据/日志可能已含正文，不能称未披露或完全未执行；派发回执也不宣称提供商已消费正文。历史配置回执不是“当前仍生效”的证明，需刷新 head。

## 中断与未知结果

所有 API 请求独立使用 no-store 和 AbortSignal，不加入 URL-only 请求合并；公司、用户、session、授权核验及 prompt 切换使旧响应失效。读权限撤销清空界面详情、草稿和确认，原未知写入元数据保留以防止另建请求。

sessionStorage 只保存严格白名单的公司/用户/session/请求/目标标识、代次、审批摘要，以及 prepare 原请求中的 comparison UUID 列表、数值成本上限和审批有效分钟数。不保存提示词正文、模型输出、secret 值、完整快照或已勾选的授权状态。存储写入和回读确认失败时，不发送变更。

未知写结果阻止新请求。优先只读查询同一 requestId；没有查到结果不表示原写入被取消。用户也可明确确认后重试同一个 requestId 和固定 payload；不会自动重放或生成替代 ID。审批重试必须重新读取原提案详情、核对 actor/target/digest/generation 并重新勾选四项和重试确认；回退重试也重新确认。

纯 prepare 允许操作者显式放弃本地元数据恢复，严格比较原账本身份；服务端仍可能留下未应用提案，不表示取消服务端，也不适用于审批或回退。

若原审批/回退写入未到达服务端，而审批期限已过或目标代次已前移，恢复查询会带上固定的 applicationId/action/expectedGeneration。只有服务端在同请求/目标锁内等待旧 writer、先查回执、再确认单调代次前移或待批过期后，返回精确匹配 requestId/action/applicationId/agentId/generation 的 `not_applied_closed` 证明，界面才清除恢复账本。普通 404/409/422、空查询、外国目标或冲突回执均不能解锁。无法得到证明时继续保持未知状态，不以清空存储或替代 ID 绕过。

## 已执行检查

- 六个定向测试文件共 97 项通过，覆盖 API 协议、严格返回验证、元数据账本、四语、显式证据移交、重复点击、StrictMode、身份/授权/导航切换、迟到响应、未知结果只读恢复及显式同 ID 重试、确定未应用证明、过期审批、关闭特性后的回退、其他管理员接管和派发分页。
- 受影响源码与测试的独立 TypeScript 无输出检查通过，512 MB Node 堆限制；shared 应用合同只读指向后端工作树。
- 三项 token gates 脚本及 git diff --check 通过。四语仅增加 contributions/promptApplicationsUi，不生成最终 locales。
- pnpm 包装命令触发其依赖自检并尝试访问不可写的全局目录，未完成；改为直接执行相同三项已安装脚本，没有安装依赖或修改 lock。

未运行：全仓构建/类型检查、浏览器视觉验收、真实 PostgreSQL、真实 Claude/模型调用、费用或外发、真实应用启用。测试通过不能替代这些验收，也不能证明完整模型上下文或普通工具质量。

### 准备阶段可见性与会话历史

准备前说明部署元数据对本公司有权限的owner/admin可见；只包含版本/数据集/测试ID与费用上限，不包含私有case、输出或prompt正文。应用时另确认普通日志/工具受众。后续session可能保留首次输入，回退只管未来绑定，不能清除既有会话历史。
